# Nós de Fibra

Sistema de gestão do ponto de cultura Nós de Fibra (estoque, vendas e dinheiro).

## Como rodar

1. Instale o Node.js (versão LTS) se ainda não tiver.
2. Abra a pasta do projeto no terminal e rode `npm install` (só é preciso quando o package.json mudar).
3. Rode `npm run dev` e abra o endereço que aparecer (normalmente http://localhost:5173).

Para testar no celular, com o computador e o celular na mesma rede Wi-Fi, rode `npm run dev -- --host` e abra no celular o endereço de rede que o terminal mostrar.
